This page demonstrates how to use the MetricPanel SDK for tracking analytics events.

1. Track Pageview

Track a pageview event manually:

await metricpanel.pageview()

2. Track Custom Events

Track user interactions and custom events:

await metricpanel.event('button_click', { button: 'example' }) await metricpanel.event('search', { query: 'analytics', results: 42 }) await metricpanel.event('form_submit', { form_id: 'contact' })

3. Track Revenue

Track purchases and revenue:

await metricpanel.revenue({ amount: 2999 }) await metricpanel.revenue({ amount: 4999, currency: 'usd', productId: 'prod_123', productName: 'Premium Plan' })

4. Track Goals

Track goal conversions:

await metricpanel.goal({ name: 'signup' }) await metricpanel.goal({ name: 'purchase', value: 4999 })

5. Stripe Integration

Get metadata for Stripe checkout:


      

        const metadata = metricpanel.getStripeMetadata() // Include in Stripe checkout session
        metadata: metadata
